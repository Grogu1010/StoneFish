SETTINGS API access ⌄

Use StoneFish on another website

StoneFish has a browser API for external sites. It runs the engine locally in the visitor’s browser, so there is no API key and no board data has to be sent to a StoneFish server.

Released models only

The public API includes v1, v2, v3, v4, v4.5, v5, v5 Pro, and v5.5. Developer controls, No-ARMX builds, and Athena/Ares/Artemis testunits are deliberately unavailable through the API.

1. Add the loader

Put this script on the page that will use StoneFish. The loader fetches the released engine files from the same CDN base automatically.

<script src="https://cdn.jsdelivr.net/gh/Grogu1010/StoneFish@main/stonefish-api.js"></script>

For a production site, pin the URL to a release tag or commit instead of @main so your integration does not change unexpectedly.

2. Wait until StoneFish is ready

await StonefishAPI.ready;

console.log(StonefishAPI.listModels());

listModels() is the supported source for model pickers. It only returns released models.

3. Create a game

You can start from the normal initial position or replay a move history. Move strings use UCI notation such as e2e4, g1f3, or e7e8q.

const game = await StonefishAPI.createGame([
  'e2e4',
  'e7e5',
  'g1f3'
]);

4. Ask a model for a move

const answer = await StonefishAPI.getMove('v55', game);

console.log(answer.move.uci);
// example: "b8c6"

getMove() does not apply the selected move. The result includes the model id/name, move details, current FEN, and side to move.

5. Apply moves

Apply a user move with playMove(), or choose and apply the engine move in one call with playBestMove().

await StonefishAPI.playMove(game, 'f1b5');

const reply = await StonefishAPI.playBestMove('v55', game);
console.log(reply.move.uci);

Complete example

<script src="https://cdn.jsdelivr.net/gh/Grogu1010/StoneFish@main/stonefish-api.js"></script>
<script>
(async () => {
  await StonefishAPI.ready;

  const game = await StonefishAPI.createGame(['e2e4']);
  const result = await StonefishAPI.playBestMove('v55', game);

  document.querySelector('#engine-move').textContent =
    result.move ? result.move.uci : 'Game over';
})();
</script>

API reference

StonefishAPI.ready — Promise that resolves after all released engine dependencies are loaded.

StonefishAPI.listModels() — returns the released model ids and display names.

StonefishAPI.createGame(input?) — creates a game from the starting position, a FEN string, a move array, or { fen, moves }.

StonefishAPI.getMove(modelId, state?) — calculates a model move without applying it. State can be a StoneFish game, FEN string, move array, or { fen, moves }.

StonefishAPI.playMove(game, move) — applies a legal UCI move or { from, to, promotion } object.

StonefishAPI.playBestMove(modelId, game) — calculates and applies the model’s move.

Performance note

The stronger engines do real search in the browser and can use noticeable CPU time. Disable repeated UI clicks while awaiting a move. Sites running many games at once should use workers or their own queue.
